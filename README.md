<h1 align="center">HESAP MAKİNESİ (Calculator)</h1>

## Turkish

Python ile yapılmış, konsolda çalışan basit bir hesap makinesidir.

### Özellikler

- 4 işlem: `+`, `-`, `*`, `/`
- Kare alma: `kare`
- Zincirleme işlem: sonuç ekranda kalır, sonraki işlem onun üzerinden devam eder
- Temizleme: `ac` yeni işleme başlar
- Çıkış: `q`
- Hatalı giriş ve sıfıra bölme kontrolü

Örnek:

```
SAYI1 GİR:45
(+, -, *, /, kare, ac, q):+
SAYI2 GİR:45
->>SONUÇ:90<<-
(+, -, *, /, kare, ac, q):kare
->>SONUÇ:8,100<<-
```

### Gereksinimler

Python 3. Ek kütüphane gerekmez.

---

## English

A simple calculator made with Python that runs in the console.

### Features

- 4 operations: `+`, `-`, `*`, `/`
- Square: `kare`
- Chained calculations: the result stays on screen and the next operation continues from it
- Clear: `ac` starts a new calculation
- Exit: `q`
- Invalid input and division by zero handling

Example:

```
SAYI1 GİR:45
(+, -, *, /, kare, ac, q):+
SAYI2 GİR:45
->>SONUÇ:90<<-
(+, -, *, /, kare, ac, q):kare
->>SONUÇ:8,100<<-
```

### Requirements

Python 3. No extra libraries needed.

`kare` = square, `ac` = clear, `q` = quit
